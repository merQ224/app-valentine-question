# app-valentine-question

An interactive App to send to your valentine to ask if they will be your valentine.

-----

## Features
- Yes/No interactive buttons
- Dynamic reject messages
- Final No button interaction causes button to dodge the mouse
- Animated success page with heart and Confetti

-----

## Getting Started

### 1. Clone Repository
git clone https://github.com/merQ224/app-valentine-question.git

### 2. Install Dependencies
"npm install"

-----

## Run development server
npm run dev

## Build for production
npm run build

## Preview production build
npm run preview
